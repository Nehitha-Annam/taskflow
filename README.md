# TaskFlow

A frontend-only smart task management system.

## Technologies
- HTML
- CSS
- JavaScript
- Browser LocalStorage

## Features
- User registration and login
- User-specific task storage
- Add, edit, delete and complete tasks
- Task description, category, priority and due date
- Search and filters
- Dashboard statistics
- Analytics
- Due-date notifications
- Dark/light mode
- Responsive design

## Run
Open `index.html` in a browser, or use VS Code Live Server.

No backend, Node.js, Express, SQLite, JWT or database server is required.

> Note: LocalStorage authentication is intended for a frontend/demo project. It is not suitable for production security.
